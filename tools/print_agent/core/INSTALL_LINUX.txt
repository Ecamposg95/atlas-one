  ATLAS PRINT AGENT — INSTALACIÓN EN LINUX
════════════════════════════════════════════════════════════════════

Hay DOS modos. Hoy las cajas usan el manual; el de servicio es al que se
migra caja por caja.

  MANUAL (el de hoy)
    La cajera abre impresora_linux.sh y deja la ventana abierta toda
    la jornada. Al apagar la PC hay que repetirlo cada mañana.

  SERVICIO (el destino)
    El agente arranca solo al prender la PC, antes de que nadie inicie
    sesión, y systemd lo revive si se cae. La cajera no abre nada.

El runbook de la conversión tienda por tienda vive en:
  docs/superpowers/runbooks/print-agent-autostart.md


────────────────────────────────────────────────────────────────────
  PREREQUISITOS
────────────────────────────────────────────────────────────────────

  • Linux con systemd (Ubuntu 20.04+, Debian 11+, Fedora, etc.)
  • Python 3.10+ y el paquete python3-venv
  • CUPS instalado y corriendo:
        sudo apt install cups cups-client cups-bsd
        sudo systemctl enable --now cups
  • sudo (recomendado). Sin sudo el instalador cae a servicio de
    usuario, que también arranca al prender la PC.


────────────────────────────────────────────────────────────────────
  INSTALACIÓN
────────────────────────────────────────────────────────────────────

  Córrelo desde la MISMA carpeta que la caja ya venía usando: así
  encuentra y conserva el certificado que el navegador de esa PC ya
  aceptó, y nadie tiene que volver a aceptarlo.

  1. Ver qué haría, sin tocar nada:

         bash core/instalar-servicio-linux.sh --dry-run

     Confirma la línea "Certificado existente encontrado". Si dice
     "No se encontró certificado previo", habrá que re-aceptarlo en
     el navegador al terminar.

  2. Instalar:

         sudo bash core/instalar-servicio-linux.sh

  El script copia el agente a /opt/atlas-print-agent, crea el entorno
  Python, conserva el certificado, escribe la unidad systemd, la
  habilita al arranque y NO declara éxito hasta que /health responde.

  Opciones:

    sudo bash core/instalar-servicio-linux.sh cajero
        Instala bajo otro usuario del sistema.

    sudo bash core/instalar-servicio-linux.sh --origins "https://mi.dominio"
        Dominios desde los que se sirve el POS. Por omisión
        https://app.atlasone.com.mx. SIN el dominio correcto aquí una
        caja servida desde otro dominio VENDE PERO NO IMPRIME.

    sudo bash core/instalar-servicio-linux.sh --certs-from /ruta/core/certs
        Fuerza qué certificado conservar.


────────────────────────────────────────────────────────────────────
  VERIFICAR
────────────────────────────────────────────────────────────────────

         systemctl status atlas-print-agent
         curl -k https://127.0.0.1:9100/health

  Debe decir "Active: active (running)" y "enabled".

  La prueba de verdad: REINICIA la PC, no inicies sesión, y desde el
  navegador de otra máquina no se puede — inicia sesión y comprueba
  que /health ya responde sin que nadie haya abierto nada.


────────────────────────────────────────────────────────────────────
  COMANDOS ÚTILES
────────────────────────────────────────────────────────────────────

  Logs en vivo:     journalctl -u atlas-print-agent -f
  Reiniciar:        sudo systemctl restart atlas-print-agent
  Detener:          sudo systemctl stop atlas-print-agent
  Desinstalar:      sudo systemctl disable --now atlas-print-agent

  Servicio de usuario (instalación sin root): los mismos comandos con
  `systemctl --user` y `journalctl --user`.


────────────────────────────────────────────────────────────────────
  DESPUÉS DE CONVERTIR UNA CAJA
────────────────────────────────────────────────────────────────────

  La cajera va a seguir buscando impresora_linux.sh por costumbre.
  Eso ya no falla: el script detecta que el servicio está activo y
  muestra "El agente YA ESTA ACTIVO / puedes cerrar esta ventana".

  Lo que el autoarranque NO resuelve, y sigue siendo por PC:
    • Aceptar el certificado en el navegador (se conserva si el
      instalador encontró el certificado viejo).
    • El permiso "Acceso a la red local" de Chrome, que se pide por
      sitio y por PC. Si además cambias el dominio del POS, hay que
      concederlo de nuevo en esa terminal.


────────────────────────────────────────────────────────────────────
  MODO MANUAL (el de hoy, y para diagnóstico)
────────────────────────────────────────────────────────────────────

         bash impresora_linux.sh

  Corre en primer plano; al cerrar la ventana se detiene. Instala CUPS
  y el entorno si faltan. En una caja ya convertida, avisa y sale sin
  hacer nada.
